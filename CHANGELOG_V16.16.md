# V16.16 — Guided Home Screen Installation

## Settings
- Added a compact **Add BrineSearch to Home Screen** option under App and offline access.
- Users choose **iPhone** or **Android**, then select the browser they are using.
- The guide shows only the steps for the selected phone and browser.
- Added browser-specific instructions for Safari, Chrome, Firefox, Samsung Internet, and other browsers.
- Added automatic device/browser detection while keeping all choices manually selectable.
- Remembers the user’s selected phone and browser on that device.
- Shows when BrineSearch is already running as an installed app.

## Preserved
- No existing Settings, Offline Mode, pad, Feed, editor, verification, or database features were removed or redesigned.
- Dark mode and daylight mode remain supported.

## Release
- Updated visible version labels and the PWA cache to V16.16.
