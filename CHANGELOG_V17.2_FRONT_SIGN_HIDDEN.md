# BrineSearch V17.2 — Front Sign UI hidden

- Hides the **Scan Front Sign** action from the Pad page.
- Hides the entire saved **Front Sign** photo/text card.
- Hides the Front Sign scanner panel inside **Edit Pad**.
- Removes those hidden elements from screen-reader navigation and page layout.
- Keeps the scanner code, local saved photos, and recognized scan data intact.
- Adds a small visibility switch so the feature can be turned back on later without rebuilding it.
- Keeps the hidden-state script available offline and on both Netlify and GitHub Pages builds.
