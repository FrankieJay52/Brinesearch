BrineSearch V 16.16 deployment

1. Deploy the complete contents of this folder.
2. Do not omit the icons, manifest, service worker, or fallback data.
3. Confirm the footer and Settings page show V 16.16.
4. Open Settings → Add BrineSearch to Home Screen.
5. Test iPhone and Android selections plus each available browser choice.
6. Check the installation guide in dark and daylight themes.
7. Test the existing pad actions, Add/Edit Pad steps, Feed, search, and Offline Mode.
8. If the update banner appears, tap Reload once so the V 16.16 service worker takes control.
