# V16.15 — Compact Mobile Layout

## Pad page actions
- Reduced the large action-card section on phones.
- Directions remains a full-width primary action but is much shorter.
- Apple Maps and Share now sit side by side.
- Favorite and Edit Pad now sit side by side for editors.
- Secondary descriptions are hidden on phones so the buttons remain fast and easy to scan.
- Every existing action and permission check is preserved.

## Add Pad and Edit Pad steps
- Reduced the step-navigation height on phones.
- Mobile shows five compact numbered step buttons instead of five large labeled boxes.
- Every step remains directly tappable.
- The active section name and step count remain visible below the numbered row.
- Desktop retains the section labels in a tighter layout.

## Preserved
- All fields, save behavior, validation, permissions, directions, Maps links, favorites, sharing, dark mode, and light mode.
