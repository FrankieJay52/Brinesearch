# `urgent_security_hardening`

These eight numbered SQL files, concatenated in filename order (`00.sql` through `07.sql`), are the exact source for the live Supabase migration named `urgent_security_hardening`.

They are split only to keep the review and connector payloads manageable. Do not run an individual part by itself. The migration captures pre-change definitions and ACLs before changing authorization, and it does not alter pad directions, road facts, turns, mileage, or Clear Directions data.
