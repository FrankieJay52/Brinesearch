# V17.3.15 global written-direction audit

Driver direction cards now use one numbered written sentence per saved Clear Direction, based on the approved Ascent LEE prototype. Road/highway/street sign graphics are suppressed in the driver direction list.

## Live production audit before release

- 1,173 pad records checked.
- 1,063 pads currently have Clear Directions; 110 do not.
- Of the 110 without Clear Directions, 19 retain written source directions, 4 retain a structured road sequence, and 91 have neither written nor structured direction evidence. V17.3.15 does not manufacture turn-by-turn directions for these records.
- 5,464 direction-intelligence source steps checked.
- 2,496 steps have a recognized road.
- 1,228 state-route steps, 625 county-road steps, 104 township-road steps, and 486 I/US steps.
- 205 steps currently carry a second local road name.
- 146 of those aliases are literal in the saved source instruction; 59 are supplied by the audited road-intelligence layer.

## Double-name safety

A numbered road is not assumed to have one local name county-wide. The audit found real examples where one county-road number has different local names on different segments, including CR-10, CR-56, CR-64, CR-26, CR-2, and others.

V17.3.15 therefore follows these display rules:

1. Preserve explicit double names and route concurrencies exactly when the saved direction contains them, in either order (`CR-24 / Cow Path Rd` or `Fernwood-Bloomingdale Rd / CR-26`).
2. Preserve state-route/local-street pairs such as `OH-151 / Mill St` and route concurrencies such as `OH-147 / OH-149`.
3. Add a second name from shared direction intelligence only when the evidence is `shared_saved_directions` with at least two bounded supporting saved routes.
4. Do not auto-inject an ODOT-catalog alias into a route-only step merely because the county-road number matches. This avoids attaching a segment-specific street name to the wrong portion of a county road.
5. Never add a third name when the saved instruction already has an explicit local-name/route-number pair.

## Driver display

- Numbered steps remain.
- Each real step is one written sentence.
- Mileage stays in that same sentence when it is saved with the step.
- Warnings/curfews remain notes instead of becoming fake steps.
- Landmark cleanup remains active.
- Pads without verified Clear Directions show only safe route-sequence text when available, clearly labeled as not verified turn-by-turn.
- No saved GPS, directions, road sequence, mileage, wells, APIs, or properties are changed by this presentation release.
